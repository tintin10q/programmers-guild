## Purpose and occupation

The main aims of the programming guild is to:

A lot of Thalia members enjoy programming. While we have a chess guild and a go guild there is not a programming guild. Yes there is Techniecie but what if you want to do other things than building and maintaining a Django website. There is of course the Mercator chats about assignments and projects but there is no place to: 

- Improve & train our member’s programming skills
- Enjoy the art of programming together
- Teach and coach each other about programming

We will achieve these goals by holding events. Here are event ideas that we came up with:

We came up with these activities:

- LeetCode Together evenings
    - We will host our own LeetCode scoreboard
    - Solve (hard) LeetCode problems in groups instead of alone. This way we learn as a group.
    - Compare solutions in different languages
- Our own programming challenges, just solve it in any way you want
    - Awards for best run‑time
    - Awards for best memory usage
    - Awards for completion order
- Advent of Code (with our own scoreboard)
- Exploring exotic programming languages/frameworks together
- Competitive programming competitions (internally & externally)
- Training for the (Benelux Annual Programming Contest) BAPCie
- Programming subjects presentations evening
    - Some members give a presentation and demo about a cool programming subject
- How to use vim and other cool coding environments setups?
- How does algorithmic complexity work again????
- W.I.P. Work on work in progress programming projects together and solve hard bugs
- Training & Coaching

We also plan to create a GitHub organization account with useful resources and things.

## External and financial

### Promotion:

We plan to promote our guild both by word of mouth as well as active campaigning within Thalia. Our first members will most likely be people we know personally. We will garner interest by hosting an open event where everyone is free to join. We will also create a poster and hang it up in Mercator. We tought it would be a fun idea that you would have to solve a programming puzzle (on the poster) in order to get the invite link.

### Open event:

Our open events could be a programming challenges & tournaments night.

We split up in pairs of 2 with the same 2 leet code questions and make a competition out of it. The best x number of teams then move on to another round with harder programming challenges and then we have a final round. We also have a losers bracket with an easier question.  

### Finance:

As far as we are currently aware, we don't need any external initial investments to get started. However, it would be great to have a room in Mercator or Huygens available for our events. Financing may be needed in the future, especailly if we want to participate in programming competitions (think travel cost or merch) but not at the current stage of our guild.
